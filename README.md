## Heap Data Structures: Implementation, Analysis, and Applications

This repository contains a manual implementation of Heapsort, an array-backed max-heap priority queue, a priority-based scheduler simulation, and an empirical comparison of Heapsort, Randomized Quicksort, and Merge Sort.

## Files
- `heapsort.py` - Heapsort using a max heap.
- `priority_queue.py` - `Task` class and max-heap priority queue with insert, extract-max, increase-key, decrease-key, peek, and is-empty operations.
- `scheduler.py` - Simple priority-based task scheduling simulation.
- `benchmark.py` - Runtime comparison across random, sorted, and reverse-sorted input distributions.
- `results/benchmark_results.csv` - Benchmark measurements generated by `benchmark.py`.
- `results/sorting_performance_*.png` - Performance graphs generated by the benchmark.

## Requirements
Python 3.8 or newer. `matplotlib` is optional and is only required to generate charts.

## Run
```bash
python heapsort.py
python priority_queue.py
python scheduler.py
python benchmark.py
```

## Summary of Findings
Heapsort has O(n log n) best-, average-, and worst-case running time and uses O(1) auxiliary space when implemented in place. The max-heap priority queue performs insertion, extraction, and key adjustments in O(log n), while checking whether the queue is empty is O(1). The benchmark compares these theoretical properties with observed execution times on multiple input sizes and distributions.
